MY TRAINING — GITHUB READY (v4 bilingual)

Upload ALL files in this folder to the ROOT of a separate GitHub repository (recommended name: my-training).
Then enable GitHub Pages: Settings > Pages > Deploy from a branch > main / root.

Suggested URL:
https://armannsb.github.io/my-training/

Cloud sync is already pointed at the separate my-training-sync Supabase Edge Function.
On first use: open Settings > Cloud sync and enter YOUR private MY_TRAINING_SYNC_KEY.
Never commit that private sync code to GitHub.

Language:
Use the FA / EN button in the top-right. The choice is saved and synced as a preference. Workout history is the same in both languages.
