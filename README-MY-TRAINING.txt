MY TRAINING — PERSONALIZED 4-DAY PROGRAM

WHAT'S INCLUDED
- Saturday: Upper A
- Sunday: Lower A
- Tuesday: Upper B
- Thursday: Lower B
- The old external 'Six Pack in 30 Days' checkbox/app routine has been removed.
- Core work is now part of the gym program: Saturday Cable Crunch, Tuesday Cable Crunch, Thursday Hanging Knee Raise (3 sets each), with 2 clickable alternatives for every core movement.
- Every exercise has 3 clickable choices: Main + Alt 1 + Alt 2.
- Selecting an option changes its name, demo image, technique guide and YouTube search.
- Weight/reps/progress history is stored separately for each exercise option.
- The last selected option is remembered for that program slot.
- Workout logging, rest timer, history, progress charts, PWA install and offline use are included.

SAFE BESIDE THE FRIEND'S SITE
- This build uses mytraining.* browser-storage keys only.
- It does not import or read the friend's gp.* workout/timer data.
- PWA cache names use a mytraining- prefix.
